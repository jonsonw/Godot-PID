## 1. 字段元数据约定

每行字段：

| 元数据 | 含义 |
|---|---|
| `key` | 稳定技术键；模板可用 `{{key}}` 精确绑定 |
| `zh` / `en` | 默认表头文字（中文 / 英文） |
| `aliases` | 表头自动识别别名（中英文、行业习惯；大小写/空白/标点归一化后比较） |
| `source` | 取值来源，见 §2 |
| `kind` | `text` / `int` / `float:N` / `bool` |
| `required` | 该表绑定必须命中的关键列 |
| `writable` | 回写是否允许写该列 |
| `default_col` | 是否进入默认模板 |

`source` 语法：

| 写法 | 含义 |
|---|---|
| `node.tag` / `node.name` | 节点位号 / 显示名 |
| `def.display` / `def.category` | 图元定义显示名 / 类别 |
| `dexpi.class` | `GPDexpiMapping.gpComponentFor()` 的类名 |
| `edge.tag` / `edge.kind` | 边位号（管线号）/ 边类型 |
| `edge.attr:<k>` | 边属性 `dn/medium/spec/insulation` |
| `prop:<k>` | 节点 schema 有效值 |
| `computed:<name>` | 由模型计算，见各表说明 |
| `sheet.name` | 图纸标签名 |

## 2. 管线一览表 `line`

| key | zh | en | 主要别名 | source | kind | required | writable | default_col |
|---|---|---|---|---|---|---|---|---|
| `no` | 序号 | No. | Item / 序号 | `computed:no` | int | ❌ | ❌ | ✅ |
| `sheet` | 图纸 | Sheet | Drawing / 图号 | `sheet.name` | text | ❌ | ❌ | ✅ |
| `line_no` | 管线号 | Line No. | 管道号 / 线号 / Line Number | `edge.tag` | text | ✅ | ❌（键） | ✅ |
| `line_kind` | 管线类型 | Line Type | 线型 / Service | `edge.kind` | text | ❌ | ❌ | ✅ |
| `from` | 起点 | From | 起始 / Start | `computed:from` | text | ❌ | ❌ | ✅ |
| `to` | 终点 | To | 止点 / End | `computed:to` | text | ❌ | ❌ | ✅ |
| `from_equipment` | 起点设备 | From Equipment | — | `computed:from_equipment` | text | ❌ | ❌ | ✅ |
| `to_equipment` | 终点设备 | To Equipment | — | `computed:to_equipment` | text | ❌ | ❌ | ✅ |
| `dn` | 公称直径 | DN | 管径 / Size / Nominal Diameter | `edge.attr:dn` | text | ❌ | ✅ | ✅ |
| `spec` | 管道等级 | Piping Class | 等级 / Spec | `edge.attr:spec` | text | ❌ | ✅ | ✅ |
| `medium` | 介质 | Medium | 流体 / Fluid | `edge.attr:medium` | text | ❌ | ✅ | ✅ |
| `insulation` | 保温 | Insulation | 保温等级 / 保温厚度 | `edge.attr:insulation` | text | ❌ | ✅ | ✅ |
| `length_m` | 长度(m) | Length | 长度 | `computed:length_m` | float:2 | ❌ | ❌ | ✅ |
| `valves` | 阀门 | Valves | 阀门位号 / Valve Tags | `computed:valves` | text | ❌ | ❌ | ✅ |
| `valve_count` | 阀门数 | Valve Count | 阀门数量 | `computed:valve_count` | int | ❌ | ❌ | ❌ |
| `segment_count` | 管段数 | Segments | 管段数量 | `computed:segment_count` | int | ❌ | ❌ | ❌ |

**行规则**

- 按 `line_no` 合并同号边；跨图纸同号视为同一根管线，`sheet` 列逗号分隔。
- `line_kind`：`PROCESS` → 「工艺管线」；`UTILITY` → 「公用工程管线」；SIGNAL 边不进管线表。
- `from`/`to`：优先取组内边的**非管件**端点，按图面坐标排序取首尾；两端都是管件时写管件位号，`*_equipment` 留空。
- `from_equipment`/`to_equipment`：端点若是挂载子件（管口），沿 `gpParentUid` 上溯到顶层设备。
- `length_m`：组内每条边的解析折线长度累加 ÷1000，2 位小数；解析失败跳过并报告。
- `valves`：该组边上**阀门类别**节点去重后的位号，按自然排序逗号分隔；无位号阀门写 `<无位号:类型>` 并报告。
- `valve_count`：`valves` 的元素数（去重后）。
- `segment_count`：该组边的条数。
- 分支：同一管线号 >2 个非管件端点时，`from`/`to` 全部列出（逗号分隔）并报告。

**回写**

- 键：`line_no`。
- 可写：`dn` / `spec` / `medium` / `insulation`。
- 一笔管线号可能对应**多条边**：回写作用于该图纸内该管线号下的**全部边**。
- 空白 = 清空：删除该边属性键，回到「未设置」。
- 只读列（含 `valves`）即使被编辑也忽略并报告。

## 6. 分类规则

| 图元类别 / 角色 | 归属 |
|---|---|
| `pump` / `tank` / `heat` | 设备表 |
| `instrument` | 仪表表 |
| `valve` | 阀门表 |
| `general` + role `piping_component`（盲板/异径/三通） | **不导出** |
| `general` + role `equipment`（人孔/管口） | 挂载子件，计入宿主管口数，不单独成行 |
| role `actuating`（执行机构） | 挂载子件，不单独成行 |
| role `annotation`（箭头/坡度/保温剖面） | 不导出 |
| 未知 / 用户自建 | 设备表兜底 + 报告 |
| 任何 `gpParentUid != ""` | 挂载子件，不单独成行 |

- 分类覆盖测试遍历全部内置图元，断言每个都有明确归属（含「不导出」）。
- 阀门与设备互斥；设备表出现阀门 = 缺陷。
- 管件完全不产生行；管线表 `valves` 列只列阀门，不列管件。

## 7. 回写总则

### 7.1 匹配

| 清单 | 键 | 匹配范围 | 多义 |
|---|---|---|---|
| `line` | `line_no` | 行「图纸」列对应的图纸内，同号 PROCESS/UTILITY 边 | 全部更新 |
| `equipment` / `instrument` / `valve` | `tag` | 行「图纸」列对应的图纸内顶层节点 | **跳过并报告** |

- 支持**多图纸回写**：按每行的「图纸」列分组；无「图纸」列时，按位号在各图纸中查找。
- 同一 `tag` 在多张图纸出现：若行带图纸列，用图纸消歧；否则**跳过并报告**，不猜。
- 精确匹配优先；找不到再按 `GPTagRegistry.gpNormalize()` 归一化匹配，并报告。
- 未匹配键：报告 `import.unmatched_key`，**绝不新建对象**。

### 7.2 可写与空白

- 只写 `writable == true` 的字段；只读列编辑/空白都忽略。
- **空白 = 清空**：
  - 节点属性：删除 `gpProps[key]`，回到库默认；
  - 名称：删除 `gpNames[fallback]`，显示回落库名/位号；
  - 边属性：删除 `gpAttrs[key]`。
- 值未变化 → 不产生变更、不压撤销步。
- 位号/管线号为键：空白行跳过，绝不删除对象。
- 不新增/删除图元，不改几何/连接/挂载，不改位号。

### 7.3 多图纸与撤销

- 变更按图纸分组；每张图纸一条 `GPApplyListChangesCommand`，压入该图纸画布的撤销栈。
- **每张图纸各自可撤销**：在当前图纸按 Ctrl+Z 只回退当前图纸；其他图纸切过去再撤销。
- 预览按图纸分列；应用时可勾选要应用的图纸（默认所有有变更的图纸）。
- 一张图纸失败不连累其他图纸；逐图报告。
- 执行时若当前值与预览时的旧值不同（预览后被改过），该条跳过并报告 `import.stale_value`。

### 7.4 一键预览必须显示

- 每张图纸：匹配行 / 变更项 / 清空项 / 未匹配 / 跳过；
- 全局：只读列、未知列、重复位号、stale、错误；
- 明确提示：「空白单元格将清空属性；不会新增或删除图元；撤销按图纸各自生效」。

## 8. 表头别名规则

- 归一化：去首尾空白、去全角/半角标点（`（）【】：，。、/\\-_·` 等）、转小写、合并连续空白。
- 先精确匹配，再「包含」匹配（别名长度 ≥2，避免 `No` 命中 `Nozzle`）。
- 别名来源：本文件静态别名 → 本次涉及图元的 schema 标签（`gpLabel` / `gpKey`）→ 用户上次映射。
- 一个表头命中多个字段：关键字段 > 静态目录 > 扩展字段；报告 `xlsx.field_ambiguous`。
- 一个字段出现在多列：两列都写，报告 info。
- 列令牌 `{{key}}` / `{{prop:key}}` 优先于别名；`project.*` / `export.*` / `list.*` / `sheet.*` 是文本令牌，不是列。

## 9. 变更控制

1. 改字段 key：必须保留旧 key 的迁移/别名至少一个版本，并在本文件记录。
2. 改别名：同步测试；别名冲突必须报告。
3. 改可写性：默认「不加可写」，加可写必须过 ADR-32 的「只写属性」审查。
4. 改默认模板列：同步四套模板 + `default_col` 测试。
5. 任何改动都要更新：本文件 → ADR-32 → 模板说明 → 测试 → 用户可见的变更记录。
