# G-PID 数据清单 i18n 键清单 v1

> **状态**：P0 冻结（2026-10-19）
> **范围**：Excel 数据清单导出 + 属性回写
> **配套**：`清单字段目录_v1.md`、`清单模板说明.md`；决策见 ADR-32（内部）
>
> 本文件冻结 key 的**命名与用途**，不冻结最终译文。英文译文在 P5 补齐；`gp_test_ui_i18n_refs` 要求每个 key 的 zh/en 都非空，缺一个即红。

## 7. 规则

1. 每个 key 必须在 `I18n.GP_STRINGS` 同时有非空 `zh` 与 `en`；缺一个测试即红。
2. 字段标签键由字段目录的 `label_key` 派生；**不要**在对话框里手写字段中文。
3. 错误/警告键与错误码一一对应；新增错误码必须同时加键。
4. 旧 CSV 的 `status.list_exported` 保留，不改语义；新 Excel 导出用 `status.xlsx_exported`。
5. 菜单标签键由 `menu.` 域；不要在 UI 里拼字符串。
6. 改 key = 改契约：同步字段目录、模板说明、ADR-32、测试。
