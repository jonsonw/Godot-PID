# G-PID 数据清单模板说明

> 适用：G-PID `0.1.x` 的「导出 → 数据清单（Excel）」与「导入 → 从 Excel 更新属性」
> 契约版本：v1（2026-10-19）｜配套：`清单字段目录_v1.md`；决策见 ADR-32（内部）
>
> 先说结论：**默认模板开箱即用；用自己的模板时，表头写标准叫法即可自动认列，认不出时在表头单元格写 `{{字段}}`。手动列映射下拉尚未实现（见 §9），当前用令牌/别名最稳。**

---

## 1. 三分钟上手

### 1.1 用默认模板

1. `文件 → 导出 → 数据清单（Excel）…`
2. 勾选要导的清单：**管线 / 设备 / 仪表 / 阀门**（可只选一类）。
3. 勾选图纸（默认全选；可全选/全不选/逐张）。
4. 选输出目录，点「导出」。
5. 每类清单一套默认模板、一个 `.xlsx`；没有封面，项目信息在每张表顶部。

### 1.2 用公司模板（推荐从默认模板改）

1. 在导出对话框里，对某一类清单点「保存默认模板…」，得到一份 `.xlsx`。
2. 在 Excel 里改样式、加列、改表头、调打印设置。
3. 回到对话框，点该类清单的「选择模板…」选中它。
4. 程序按表头自动认列；认不出的列可在表头写 `{{key}}` / `{{tag}}` / `{{line_no}}` 令牌；手动映射下拉尚未实现（见 §9）。

### 1.3 从 Excel 回写属性

1. 导出清单 → 在 Excel 里补齐/修改属性（**只改属性列**）。
2. `文件 → 导入 → 从 Excel 更新属性…`
3. 选文件（可多个）→ 预览：匹配多少行、改多少项、清空多少项、哪些没匹配。
4. 确认「应用」→ 每张图纸各自一条撤销记录；`Ctrl+Z` 回退当前图纸。

> 回写只改属性：**不新增图元、不删除图元、不改位号、不改几何/连接**。

## 2. 模板长什么样

每套模板 = 一个工作簿 + 一张数据表（可以有隐藏说明表；默认不带封面）。

```
第 1–2 行：汇总区（项目名 / 图号 / 版本 / 日期 / 本次图纸数 / 行数）
第 3 行：空行
第 4 行：表头（建议带 {{GP_HEADER}}）
第 5 行：样例行（样式模板，只允许一行）
第 6 行起：页脚（编制/审核/批准 + 页码）
```

规则：

- **表头下第一行是样例行**：它的字体、边框、底色、数字格式、行高会被克隆到每一条数据。
- **只支持单行表头**：两行/三行表头（如合并的 QTY Op/St、Press Op/Des）请先压成一行表头，或把多行表头当固定页眉保留在数据区之外。列令牌必须写在表头行、或紧邻表头的样例行；写在更下面的行会被 `sample_row` 拒绝。
- **模板里不要保留旧数据行**：样例行以下、页脚以上不能有上一版清单的真实数据；当前填充器只替换样例行及页脚，不会自动删除旧数据。请先删成空白样例行，或另存为一个干净模板。
- **样例行只能有一行**；它下面的都按页脚处理，导出时随行数整体下移。
- 数据为 0 行时，样例行被删除，页脚上移。
- 单元格里的 `{{project.*}}` / `{{export.*}}` / `{{list.*}}` / `{{sheet.*}}` 会被替换；不认识的令牌原样保留，并在导入预览/模板状态里提示。
- 默认模板不用 Excel「表格对象」，只用自动筛选；如果你自己的模板用了表格对象，列数一致时会同步，不一致会转成普通区域并提示。

## 3. 认表与认列

### 3.1 认表（这个文件是哪类清单）

按顺序：

1. 单元格标记：`{{GP_LIST:line}}` / `{{GP_LIST:equipment}}` / `{{GP_LIST:instrument}}` / `{{GP_LIST:valve}}`；
2. 工作表名：含「管线/管道/Line」「设备/Equipment」「仪表/Instrument」「阀门/Valve」；
3. 表头签名：命中该清单的关键列 + 特有列。

> 一个文件只填一张清单。一个工作簿里可以有多张表（封面/说明），但只有一张数据表参与填充；用 `{{GP_LIST:none}}` 或 `{{GP_SKIP}}` 标记不参与的表。

### 3.2 认列（这一列是什么字段）

按顺序：

1. 表头单元格里的 `{{字段}}` 或 `{{prop:key}}` 令牌（最可靠）；
2. 表头文字与字段别名匹配（中文/英文/行业叫法，忽略大小写、空格、全角/半角标点）；
3. 本次导出涉及的图元 schema 标签（例如泵的「密封型式」）；
4. 上次为该模板做过的手动映射。

表头只写令牌时，导出会用字段的本地化标签补上表头文字；`管线号 {{line_no}}` 这种写法会保留「管线号」并绑定字段。

**关键列**：管线表必须有「管线号」（`line_no`）；设备/仪表/阀门必须有「位号」（`tag`）。缺了这类无法绑定，会单独报错，不影响其他清单。

### 3.2.1 `no_key` 的 3 步修复

绑定失败提示 `no_key`，表示模板里**没有任何一列**能被识别为关键列：

| 清单 | 关键列 | 最省事的表头写法 |
|---|---|---|
| 管线一览表 | `line_no` | `{{line_no}}` 或 `管线号` |
| 设备一览表 | `tag` | `{{tag}}` 或 `位号` |
| 仪表索引表 | `tag` | `{{tag}}` 或 `位号` |
| 阀门一览表 | `tag` | `{{tag}}` 或 `位号` |

1. 在数据表里加一列（位置随意，建议第一列或位号列）；表头写上面的令牌/文字。
2. 该列的样例行留空；导出时程序会写入位号/管线号，用于匹配与回写。
3. 重新选择模板；状态应从「缺少关键列：tag/line_no」变成「已绑定：表名」。

> 不能拿「序号」「名称」当关键列：回写要靠位号/管线号唯一匹配，序号不是稳定标识。
> 导出后该列仍是只读的：在 Excel 里改位号/管线号不会被回写。

### 3.3 常用标记

| 标记 | 写在哪 | 作用 |
|---|---|---|
| `{{GP_LIST:line}}` | 任意单元格（通常 A1） | 本表 = 管线一览表 |
| `{{GP_LIST:equipment}}` | 同上 | 本表 = 设备一览表 |
| `{{GP_LIST:instrument}}` | 同上 | 本表 = 仪表索引表 |
| `{{GP_LIST:valve}}` | 同上 | 本表 = 阀门一览表 |
| `{{GP_HEADER}}` | 表头行任一单元格 | 强制本行为表头行 |
| `{{GP_LIST:none}}` / `{{GP_SKIP}}` | 任意单元格 | 本表不填数据；`GP_SKIP` 同时跳过令牌替换 |
| `{{GP_COVER}}` | 任意单元格 | 封面：只替换令牌，不填数据（默认模板没有） |

标记单元格在导出时会被清空，不会留在交付物里。

## 4. 汇总区令牌

| 令牌 | 内容 |
|---|---|
| `{{project.name}}` | 项目名称（第一张所选图纸的图签 `project`） |
| `{{project.title}}` | 图名（图签 `drawing_title`，空则图元数据标题） |
| `{{project.drawing_no}}` | 图号（多张图纸去重后逗号分隔） |
| `{{project.rev}}` | 版本 |
| `{{project.date}}` | 图签日期 |
| `{{project.company}}` | 公司/设计院 |
| `{{project.sheet_count}}` | 本次勾选图纸数 |
| `{{sheet.list}}` | 本次勾选图纸名，逗号分隔 |
| `{{export.date}}` | 导出日期 `YYYY-MM-DD` |
| `{{export.datetime}}` | 导出时刻 `YYYY-MM-DD HH:MM` |
| `{{list.line.count}}` | 管线行数 |
| `{{list.equipment.count}}` | 设备行数 |
| `{{list.instrument.count}}` | 仪表行数 |
| `{{list.valve.count}}` | 阀门行数 |

- 未勾选的清单不构建，计数为 0。
- 多张图纸时，项目名/公司取第一张非空，图号去重，版本/日期取第一张非空。
- 不生成封面；这些令牌放在各表顶部汇总区即可。

## 5. 回写规则（重点）

### 5.1 能改什么

| 能改 | 不能改 |
|---|---|
| 节点属性（该图元 schema 声明过的） | 位号 / 管线号（键） |
| 节点名称 | 类型 / 类 / 类别 / 序号 / 图纸 |
| 边属性 `dn` / `medium` / `spec` / `insulation` | 起止点 / 长度 / 管段数 / 连接关系 / 数量 / 阀门列 |
| 备注（如果该图元有 `remark`） | 几何、连接、挂载、图元 id |

### 5.2 空白 = 清空

- **空白单元格 = 清空该属性**：节点属性回到图元库默认；名称回到库名/位号；边属性回到「未设置」。
- 这不是「不修改」。**只想改几列时，不要把不想改的列留空**——请保留原值，或只导出/只勾选你要改的清单。
- 值没变化不会产生变更，也不会压撤销步。
- 只读列（位号、管线号、类型、长度、阀门列等）即使被编辑也忽略。
- 位号/管线号空白：该行跳过，**不会删除对象**。

### 5.3 匹配与多图纸

- 管线按「管线号」匹配；设备/仪表/阀门按「位号」匹配。
- 同一图纸内一个位号匹配多个对象：**跳过并报告**，不猜。
- **多图纸回写**：按每行的「图纸」列分组；预览按图纸显示；应用时每张图纸各生成一条撤销记录。
- **撤销按图纸各自生效**：在当前图纸按 `Ctrl+Z` 只回退当前图纸；其他图纸切过去再撤销。UI 会明确提示。
- 预览后被别人改过的单元格：跳过并提示「预览后已变化」，不覆盖。

### 5.4 一次回写的完整流程

```
选文件 → 认清单/认列 → 按图纸分组匹配 → 预览
  → 每图：匹配 N 行 / 变更 M 项 / 清空 K 项 / 未匹配 / 跳过
  → 勾选要应用的图纸（默认全部有变更的）
  → 应用（每图一条撤销）
  → 文档变脏，Ctrl+S 保存
```

## 6. 支持与不支持

| 内容 | 支持 | 说明 |
|---|---|---|
| `.xlsx` | ✅ | 唯一格式 |
| `.xlsm`（宏） | ❌ | 明确拒绝，请另存为 `.xlsx` |
| `.xls`（旧版） | ❌ | 明确拒绝 |
| 加密工作簿 | ❌ | 明确拒绝 |
| 封面 | 可选 | 默认模板没有；自己的模板可以有，用 `{{GP_COVER}}` |
| 合并标题/表头/页脚 | ✅ | 数据区外的合并不动 |
| 数据区内合并 | ⚠️ | 单行合并逐行复制；多行合并移除并提示 |
| 自动筛选/打印区域/冻结 | ✅ | 随行数扩展 |
| 条件格式/数据验证 | ⚠️ | 范围扩展；复杂规则不改写 |
| Excel 表格对象 | ⚠️ | 列数一致时同步 `ref`；否则转普通区域并提示 |
| 图表/图片/透视表 | ⚠️ | 保留不更新；位置不随行移动，提示 |
| 一张表放多张清单 | ❌ | 一个文件只填一张清单，请拆表 |
| 一张表多个样例行 | ❌ | 只有表头下第一行是样例行 |

## 7. 常见问题

**Q：Excel 打开提示「需要修复」？**
A：把模板发我，并保留导出文件；这是最高优先级问题。临时可先用默认模板导出。

**Q：我的表头叫「设备编号」，认不出来？**
A：优先把那个表头改成 `{{tag}}`（或 `Tag` / `位号`）；也可以把「设备编号」加进字段别名（需改字段目录 + 测试）。当前版本**没有**手动映射下拉，导出对话框的模板状态会直接显示缺哪一列。

**Q：为什么管线表没有管件？**
A：按拍板，管件（盲板/异径/三通）不导出；管线表保留「阀门」列，只列阀门位号。管件仍参与长度计算与图形。

**Q：为什么设备表里没有阀门？**
A：阀门单独出「阀门一览表」；设备表只放泵/罐/换热器等主机设备。

**Q：回写把我不想要的属性清空了？**
A：空白=清空是本期契约。回写前预览会单独显示「清空 K 项」；只想改几列时，保留其他列的原值。误操作可在对应图纸 `Ctrl+Z` 撤销。

**Q：多图纸回写后按一次 Ctrl+Z 只退了一张图？**
A：这是本期契约：每张图纸各自一条撤销记录。切到其他图纸再 `Ctrl+Z`。全局一次撤销放 P1 评估。

**Q：`.xlsm` 模板能用吗？**
A：本期不能。请在 Excel 里另存为 `.xlsx`；宏不会保留。

**Q：我的表头是多行的（Item 位号下面还有 Op/St 子表头），为什么报 sample_row？**
A：当前契约是**单行表头 + 紧邻的空白样例行**。多行表头可以被程序读到第一行，但 `{{tag}}` 写在第 8 行、表头在第 5 行时，令牌不在表头下一行，会被 `sample_row` 拒绝。请把多行表头压成一行（例如 `QTY Op`、`QTY St` 各占一列），表头下一行留一个空白样例行；旧数据行删掉。多行表头/旧数据自动替换是后续增强。

**Q：为什么有些双语表头「Item 位号」能认成位号，有些不能？**
A：`Item` 也是「序号」的别名；P7 已让**关键列优先**，`Item 位号` 现在映射到 `tag`。若仍有歧义，直接把表头写 `{{tag}}` 最稳。

**Q：模板会被改吗？**
A：不会。导出只读模板；输出写新文件。输出路径等于模板路径会被拒绝。

## 8. 给实施者的检查清单（P0 契约）

- [ ] 四类清单字段与 `docs/清单字段目录_v1.md` 一致；`valves` 列存在且不含管件。
- [ ] 模板结构、标记、令牌、数据区规则与 ADR-32 一致。
- [ ] 回写：空白=清空、只读列、多图纸按图撤销、stale 跳过，均有明确规则。
- [ ] 不支持项（`.xlsm`/`.xls`/加密/多清单一张表）有明确提示。
- [ ] 默认模板四套，无封面；汇总区图签令牌齐全。

## 9. P7 实现补充（2026-10-20）

- 随包默认模板的真实结构：第 1 行标题、第 2 行汇总令牌、第 3 行表头、第 4 行唯一空白样例行、第 5 行页脚；A3 横向、按一页宽缩放、打印区域 `A1:last`、打印标题 `1:3`。
- 默认模板的「公称尺寸」列在管线表映射到 `dn`（别名已补）；在阀门表映射到 `nominal_size`。
- 用户模板仍按本文 §3 的结构约定；表头自动识别失败时，导出对话框显示「未绑定：原因」，可换模板或恢复默认。
- 手动列映射下拉（「设备编号 → 位号」）尚未实现，作为后续增强；当前可用表头别名或 `{{tag}}` 令牌完成绑定。
